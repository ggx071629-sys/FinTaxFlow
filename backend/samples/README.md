# CSV 业务导入样例

- `billing-20.csv`：20 行，17 有效 + 2 错误 + 1 文件内重复，有效金额 1802.00。首次导入使用尚未受理这些业务号的企业；重导已受理业务会显示重复。
- `bank-2026-09.csv` / `ledger-2026-09.csv`：所属期选 `2026-09`；结果共 5 项，1 一致 + 2 差异（金额、方向各一）+ 2 单侧缺失。
- 固定 UTF-8（可带 BOM）中文列名和列序。模板可从鉴权接口下载；企业由登录上下文决定，文件不接收企业列。
- 样例不自动写入用户数据库。日期不随机器当前月份改写；其他期间可按模板修改日期并选择对应期间。
- 开票类型可用 `数电普票` / `数电专票` 或 `DIGITAL_NORMAL` / `DIGITAL_SPECIAL`；收付方向可用 `IN` / `OUT`、`收` / `付`、`收入` / `支出`。
- 保留原始文本，不推测 O/0；标准化金额最多两位小数，日期支持 `YYYY-MM-DD` 或年月日的 `/` 分隔格式。无效日期与跨期间日期均报告问题。
